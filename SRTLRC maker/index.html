Aa SRT / LRC Maker

上传音频或视频，调用云端 AI 生成带时间戳的字幕（SRT）和歌词（LRC）。生成的文件可以直接给 Music Video Creator 使用。

🔒 文件只在浏览器里解码，随后仅发送给你配置的 API；Key 只有勾选后才保存在本机。

1 API 配置

模型列表由对应服务商的 API 自动查询
可填自建代理地址；Cloudflare 直连会被浏览器 CORS 拦截。

提示：保存在 localStorage 的 Key 可被本机脚本读取，公共电脑请勿勾选。

Cloudflare 直连说明

官方 api.cloudflare.com 不允许浏览器跨域请求。请部署随附的 worker.js（Cloudflare Workers，免费），把它的地址（例如 https://xxx.workers.dev/whisper）填到上方「API 地址」。Worker 会用请求头里的 Token 与 Account ID 转发到 Whisper。
