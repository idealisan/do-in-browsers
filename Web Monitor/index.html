Web Monitor

输入一个 JavaScript 文件地址，由它用本页提供的 Canvas 持续绘制。 框架负责屏幕常亮，内容与数据完全由你的插件决定。

插件编写说明 
插件只需要使用全局对象 Monitor：

  Monitor.canvas  全屏画布元素
  Monitor.ctx     2d 上下文（已按设备像素缩放，可直接用 CSS 像素坐标）
  Monitor.width   画布逻辑宽度（px）
  Monitor.height  画布逻辑高度（px）
  Monitor.dpr     设备像素比
  Monitor.onResize(fn)  尺寸变化时回调
  Monitor.exit()  返回设置页

数据获取：在插件里自行 fetch(url)，注意跨域需目标服务器允许。

示例（demo.js）：

  const raf = () => requestAnimationFrame(frame);
  function frame() {
    const { ctx, width, height } = Monitor;
    ctx.fillStyle = '#05060a';
    ctx.fillRect(0, 0, width, height);
    ctx.fillStyle = '#2ee6a8';
    ctx.font = Math.min(width, height) * 0.1 + 'px sans-serif';
    ctx.textAlign = 'center';
    ctx.fillText(new Date().toLocaleTimeString(), width/2, height/2);
    raf();
  }
  raf();

显示期间：长按 1.5 秒、双击或按 Esc 可返回设置。
